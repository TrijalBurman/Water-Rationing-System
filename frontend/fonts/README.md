# Local fonts

Manrope and Space Grotesk are self-hosted Latin variable WOFF2 assets obtained from Google Fonts.
Each font includes its SIL Open Font License. No external font request is made by the portal.

Sources: [Manrope](https://fonts.google.com/specimen/Manrope) and [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk).
